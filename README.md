# My Portfolio SPA

Це навчальний проєкт, створений з використанням React та TypeScript.  
Проєкт представляє моє портфоліо та складається з декількох сторінок.

---

## Технології

- React
- TypeScript
- React Router
- Axios
- CSS (Flexbox, Grid)
- Open-Meteo API

---

## Сторінки проєкту

###  Про мене
Інформація про мене як Frontend Developer та мої навчальні проєкти.

###  Моє місто
Сторінка з описом мого міста (Бердичів) та виводом погоди через API.

###  Моє майбутнє
Мої цілі в IT, розвиток та план професійного росту.
